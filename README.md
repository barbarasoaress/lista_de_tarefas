# ✅ Lista de Tarefas em Python

Aplicação de terminal desenvolvida em **Python** para gerenciar uma lista simples de tarefas.

## 🚀 Tecnologia utilizada

- Python

## ✨ Funcionalidades

- Adicionar tarefas
- Listar tarefas cadastradas
- Marcar tarefas como concluídas
- Excluir tarefas
- Identificar visualmente tarefas pendentes e concluídas
- Menu interativo no terminal

## ▶️ Como executar

1. Tenha o Python instalado.
2. Baixe ou clone este repositório.
3. Execute no terminal:

```bash
python index.py
```

## 📚 Objetivo do projeto

Projeto desenvolvido para praticar listas, dicionários, funções, estruturas de repetição, condicionais e interação com o usuário em Python.
